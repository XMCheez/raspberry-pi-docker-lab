# Raspberry Pi Docker HomeLab

## Overview
This Project document my installation and configuration of Docker on a Raspberry Pi 4 running Ubuntu server.

## Hardware

- Raspberry Pi 4
- Ubuntu Server
- Docker Engine
- Docker Compose
- Portainer CE

## Objectives

- Install Docker
- Verify Docker Engine
- Deploy Portainer
- Learn Docker Containers

## Skills Learned

- Linux Administration
- docker installation
- Docker images and containers
- Docker volumes
- Docker networking
- Troubleshooting network connectivity
