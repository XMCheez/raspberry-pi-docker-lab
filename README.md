# Raspberry Pi Docker Homelab

## Overview
This project documents my installation and  configuration of Docker on a Raspberry Pi 4 running Ubuntu Server.

## Hardware

- Raspberry Pi 4
- Ubuntu Server
- Docker Engine
- Docker Compose
- Portainer CE

## Objectives

- Install Docker
- Verify Docker Engine
- Deploy portainer
- Learn Docker containers

## skills Learned
- Linux Administration
- Docker installation
- Docker images and containers
- Docker volumes
- docker networking
- Troubleshooting network conenctivity
